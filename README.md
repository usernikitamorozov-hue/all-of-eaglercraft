# All of Eaglercraft

A collection of Eaglercraft versions, clients, and modified builds in one repository.

# About

all-of-eaglercraft is a collection of standalone HTML files related to Eaglercraft. The repository includes different Minecraft versions, client modifications, and experimental builds.

The goal is to keep these builds organized in one place for easy browsing and reference.

# What's Included?

The repository contains a variety of builds, including:

Eaglercraft 26.2 and 26.3

EaglercraftX 1.8

Eaglercraft 1.12.2

Eaglercraft 1.14.4

Eaglercraft 1.15.2

Eaglercraft 1.16 and 1.17

EaglercraftZ 1.20

Eaglercraft IR

EaglerForge

Eaglercraft WASM builds

Various modified clients and experimental versions

See the repository's file list for the complete collection.

# How to Use

Open the repository on GitHub.

Choose the HTML file you want to examine.

Open the file and select Raw, or download it using GitHub's download options.

Save the file with the .html extension.

Open the downloaded file in a compatible web browser.

Some builds may have specific browser requirements or features that do not work when opened locally.

# Repository Structure

The project primarily organizes builds as standalone HTML files in the repository's root directory.

Each file represents a separate build or client.
